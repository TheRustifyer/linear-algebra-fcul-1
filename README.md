## About the project

This repository shares a personal study journey through linear algebra and analytic geometry. It combines course notes with worked problems, explanations of why methods work, and connections between algebraic calculations and their geometric meaning.

The material is organised around the FCUL syllabus. Additional topics, such as LU factorisation and least squares, extend that route where they help connect ideas or solve a wider range of problems.

The collection is being developed throughout the course: chapters and solutions will gain detail as the work progresses.

## Languages

**Spanish is the base language of my notes.** It helps me absorb new ideas more easily and concentrate on the mathematics without the extra mental effort of translating as I read. This is especially useful when I am tired: studying in Spanish makes it easier to keep learning with the energy I have available.

The English and Portuguese web editions are translated automatically from Spanish with **Argos Translate** when the site is published. Each page links to its equivalents in the other languages, including the Spanish original. Equations and code retain their original notation.

| Language | Current material | Direction |
| :--- | :--- | :--- |
| 🇪🇸 **Español** | Original study notes and course index | The language in which I write and refine the material |
| 🇵🇹 **Português** | Automatically translated web edition | Read the same notes and exercises in Portuguese |
| 🇬🇧 **English** | Main website and automatically translated notes | The default language of the public web edition |

Translations follow updates to the Spanish source notes. PDFs and LaTeX documents keep the language of their original text.

## Obsidian and the web edition

💎 I write and maintain these notes in my personal [Obsidian](https://obsidian.md/) vault: a collection of Markdown documents connected through links between topics. This repository shares part of that collection, using the same notes I study and develop there.

The `.md` files retain Obsidian conventions such as `[[wikilinks]]`, callouts, and note properties. Some of that notation may appear as plain text on GitHub. References to notes elsewhere in my personal collection may also point to material that has not been published.

🌐 The web edition is built with [Quartz](https://quartz.jzhao.xyz/), which adapts the published notes for reading and navigation in a browser, including supported callouts, mathematical notation, and links between public pages. You can read the shared material online or use the available PDFs without installing Obsidian.

## How the collection grows

🌱 New notes, worked solutions, and translations are added as the course advances. The aim is a coherent route through the subject, with clear connections between concepts and enough reasoning to make the methods reusable.

Over time, the collection will also connect this material with related university courses, including physics studies at the **University of Santiago de Compostela (USC)**. The current chapter structure follows FCUL.
