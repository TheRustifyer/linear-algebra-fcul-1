\setcounter{enumi}{73}
\item {\bfseries\boldmath
Consider the real vector space $\RR^3$. Determine the real values of $a,b$ for which $(-a,1,b)$ is a linear combination of the system of vectors
}

\[
\bigl((a,1,2a),(0,1,2a),(2a,-1,a+2)\bigr).
\]

\begin{answer}
Seek $p,q,r\in\RR$ such that
\[
 p(a,1,2a)+q(0,1,2a)+r(2a,-1,a+2)=(-a,1,b).
\]
The coordinate equations are
\[
 ap+2ar=-a,\qquad p+q-r=1,\qquad 2ap+2aq+(a+2)r=b.
\]
Substitute $q=1-p+r$ in the last equation to obtain
\[
 (3a+2)r=b-2a.
\]
If $a=-2/3$, consistency requires $b=-4/3$. This condition is sufficient:
\[
 -1(a,1,2a)+2(0,1,2a)=(-a,1,-4/3)\qquad(a=-2/3).
\]
If $a\ne-2/3$, the following coefficients satisfy all three equations,
including when $a=0$:
\[
 p=\frac{a-2b-2}{3a+2},\qquad q=\frac{3b+4}{3a+2},\qquad
 r=\frac{b-2a}{3a+2}.
\]
Thus the required condition is
\[
 \boxed{a\ne-\tfrac23\quad\text{or}\quad b=-\tfrac43.}
\]
\end{answer}
